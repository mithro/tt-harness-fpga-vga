Real logs from a hand run of the build commands on tt08/tt_um_tinytapeout_logo_screensaver
(clock 25.175 MHz, nextpnr --seed 1 --timing-allow-fail, oss-cad-suite pinned by tthfv/pins.py).

nextpnr.log is complete and untrimmed.
yosys.log is cut down: the original is 11566 lines (2.6 MB); this file keeps only the final part,
from "6.50. Printing statistics." (original line 11503) to the end, which holds the cell statistics.
This design misses timing (22.04 MHz post-route against 25.17 MHz), so the fixture exercises
the FAIL form of the "Max frequency for clock" line, printed at Warning level.
Absolute paths in nextpnr.log were anonymised: the checkout prefix is rewritten to /work/tt-harness-fpga-vga/.

nextpnr-dottee.log is the complete nextpnr log of ttsky26a/tt_um_algofoogle_dottee (default synthesis, seed 1, clock 25.175 MHz), anonymised the same way.
It has TWO clocks, with the name column padded when there is more than one: a derived clock taken from
the vsync output (98.59 MHz, PASS) and the main clk (18.94 MHz, FAIL).

nextpnr-over-capacity.log and nextpnr-bad-pcf.log are complete real nextpnr-ice40 logs (same pinned suite),
made from a 9001-bit register chain (14624 LCs wanted, 5280 available) and from a pcf naming a pin the
package does not have. nextpnr exits with status 125 for both.
